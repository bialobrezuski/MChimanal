# Automated-Dual-Channel-Fluorescence-Confocal-Image-Analysis-Workflow-for-Fiji-ImageJ-1.54p-
This project is an end-to-end Python-Fiji pipeline for dual-channel fluorescence microscopy (.lsm) images. It auto-normalises channels, tests multiple ImageJ threshold models (doi:10.1117/1.1631315), extracts morphology metrics, quantifies fluorescence intensities, runs JACoP colocalisation analysis (doi:10.1111/j.1365-2818.2006.01706.x), and exports organised quantitative and visual outputs.
