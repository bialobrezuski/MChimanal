# Automated-Dual-Channel-Fluorescence-Confocal-Image-Analysis-Workflow-for-Fiji-ImageJ-1.54p-
This project is an end-to-end, Python-Fiji pipeline for dual-channel fluorescence microscopy (.lsm) images. It tests multiple ImageJ threshold models (doi.10.1117/1.1631315), extracts morphology metrics, plots fluorescence intensities and runs JACoP colocalisation (doi:10.1111/j.1365-2818.2006.01706.x).
